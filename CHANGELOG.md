# Changelog

Notable player-facing changes to Gielinor Compass are recorded here.

## [0.2.0] - 2026-08-25

First public Plugin Hub release candidate.

### Added

- Adaptive **DO NEXT** recommendations across skills, quests, gear, PvM
  preparation, Slayer, diaries, transport, clues/STASH, and resources.
- Account-aware planning for Main, Ironman, UIM, GIM variants, Hardcore
  variants, membership, and restricted builds.
- Goals plus Efficient/Balanced/Relaxed strategy and session intent.
- Recursive prerequisite and acquisition planning with bounded,
  deterministic traversal.
- Later, Not Today, Dislike, and Do This feedback stored per account, with a
  reset control.
- Compact Details and Method Guidance overlays with independent controls.
- Local-first account isolation, content freshness checks, and update tooling.

### Changed

- Streamlined the sidebar and overlays around WHAT, HOW, WHY, and NEXT.
- Selected goals now explain direct progress, prerequisite work, safe
  fallback, or state that must be checked.

### Not included

- Goal Forecast, personal XP history/rates, charts, cloud sync, hosted
  services, and supporter features remain post-publication work.
